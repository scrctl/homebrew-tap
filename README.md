# Scrctl Tap

## How do I install these formulae?

`brew install scrctl/tap/<formula>`

Or `brew tap scrctl/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "scrctl/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
